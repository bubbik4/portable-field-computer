
# Portable Field Computer

> A modular, portable, *ARM-based* and cyberdeck-like 
> computing platform, designed for field operations, 
> networking, radio apps, and general-puropse computing.

## Overview

Aims to develop a custom-built computer combining the flexibility of a Linux-based system with modular hardware or custom created enclosure.

The device is intended to function as a portable field workstation / cyberdeck rather than a conventional laptop or notebook.

## Core Features

- Full Linux OS with GUI
- Some Display
- Radio-related capabilities (WiFi, Lo-Ra, Zigbee)
- Modular hardware architecture
- GPIO and microcontroller integration
- Custom 3D-printed enclosure
