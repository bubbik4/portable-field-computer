## 2. Project Objectives

### Primary Objectives

- Run a full Linux GUI
- Provide portable networking and diagnostic tools
- Support hardware expansion and modularity
- Integrate a dedicated microcontroller
- Integrate a custom-designed enclosure
- Provide reliable portable power

### Secondary Objectives

- Integrate SDR capabilities
- Implement a custom system dashboard
- Add a dedicated status indicators
- Implement energy storage and charging station for external devices

## 4. Design Philosophy

- Modularity
- Repairability
- Expandability
- Portability

## 5. Constraints

- Limited initial budget
- Limited enclosure volume
- Power consumption
- Thermal management
- Hardware and software compatibility

## 6. Current Assumptions

- ARM SBC will serve as a main computer onboard.
- A seperate microcontroller (eg. ESP32) will handle auxiliary hardware functions
- The first prototype will use external power source
