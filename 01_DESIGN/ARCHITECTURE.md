# System Architecture

## 1. Overview

The system will be based on a modular architecture consisting of several interconnected subsystems

## 2. Main Computing Unit

Responsible for: 

- Running the main OS
- Executing user applications
- Network administration
- Storage management
- Managing external peripherals

Platform: **TBD**

## 3. Microcontroller Subsystem

Responsible for auxiliary hardware control.

Planned functions:

- Physical button inputs
- Status indicators
- Fan control
- Temperature monitoring
- Power state monitoring

Candidate: Seeed Studio XIAO ESP32-C6

## 4. Display Subsystem

Planned configuration:

- 8-inch primary display
- HDMI / DSI I-face
- USB touchscreen interface (**TBD**)

## 5. Networking Subsystem

Planned capabilities:

- Wi-Fi connectivity
- Ethernet connectivity
- External network adapters support

## 6. Radio Subsystem

Planned capabilities:

- SDR receiver integration
- USB-connected radio hardware
- Software-defines radio apps
- Lo-Ra extension board

## 7. Power Subsystem

Initial concept:

- External USB-C PD power source
- Regulated power distribution
- Separate auxiliary power monitoring

Final architecture: **TBD**

## 8. Mechanical Subsystem

- Custom 3D-printed enclosure
- Modular internal mounting
- Accessible external ports
- Dedicated control interface
